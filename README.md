# Social Media Analytics using R

## 📊 Project Overview
This project analyzes 1.6 million tweets and 5 years of website visitor data using R to extract meaningful insights through text mining, sentiment analysis, clustering, probability distribution, and time series analysis. It aims to uncover sentiment trends, word usage patterns, and user engagement behavior over time.

## 🔧 Technologies Used
- **Language:** R
- **IDE:** RStudio
- **Libraries:** `tidytext`, `tidyverse`, `ggplot2`, `dplyr`, `lubridate`, `tm`, `factoextra`, `fpc`, `clValid`, `cluster`, `nonlinearTseries`


## 🔍 Key Features
- **Text Mining:** Cleans and tokenizes tweets to extract most frequently used words.
- **Sentiment Analysis:** Uses NRC Emotion Lexicon to classify tweets into emotional categories like joy, trust, fear, etc.
- **Clustering:** Groups words with similar sentiments using hierarchical clustering and visualizes them via dendrograms.
- **Probability Analysis:** Calculates PMF and CDF to understand tweet frequency distribution.
- **Time Series Analysis:** Examines sentiment variations and tweet volumes across days.

## ✅ Outcomes
- Identified daily and emotional patterns in tweet behavior.
- Observed sentiment distribution trends (e.g., more positive sentiments during weekends).
- Integrated Twitter and website traffic data to explore user engagement comprehensively.

## 🚀 Future Enhancements
- Use of transformer-based models (BERT/GPT) for better sentiment context.
- Expand analysis to include other social media platforms.
- Real-time tweet tracking and visual dashboards.
